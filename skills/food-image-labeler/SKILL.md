# 菜品图片标注

为食品或餐桌场景图添加清晰的菜名。用户同时要求生成新场景和标注时，默认把标注直接写入每张场景生成提示词，一次生成带字成图；不要先生成无字图再单独进行标注编辑。用户要给已有图片加字时，直接编辑已有图。用户若只要提示词或文字清单，则按要求交付，不生成图片。

## 名称与对应关系

- 牛肉名称以用户提供的**牛肉产品原图文件名**为准：取文件名去掉最后的图片扩展名，保留原有中文、数字、空格和标点。不要从外观推测部位、添加“雪花”等描述、改写或合并名称。用户明确给出的名称或修订优先于文件名。
- 优先根据当前任务的生成提示词、产品编号与对应原图、图片路径和画面位置，将每一盘牛肉与对应产品文件关联；同一产品出现多份时各自使用同一名称。不要把场景成图的文件名误当作产品名。不同产品图片同名时可使用相同标签，但不得推断为同一产品。
- 文件名或对应关系无法可靠取得时，不猜测牛肉名称。独立处理能确定的部分，并用一个简短问题请用户提供缺失的原图文件名或说明哪盘对应哪张图；保留原始文件名，不擅自移除编号或其他文字。若只有对话附件且看不到文件名，也请用户提供名称。
- 配菜、锅底和蘸料根据生成场景时的提示词及实际可见内容标注。两者不一致或不确定时使用能从画面确认的概括名称；无法辨认的食材不要编造。默认给可见的菜品及锅底标注，杯具、纸巾和餐具不加菜名；遵循用户指定的范围。

## 与场景生成合并

同时使用场景创作技能时，在每张图的产品、盘子及配菜布局确定后、发起生图前，依据下方规则建立“产品原图文件名 → 盘子位置 → 精确标签”和“配菜 → 位置 → 标签”清单。将每个标签的完整原文、对应位置和文字样式直接写入该张独立完整的场景提示词；同时传入对应的原始产品图、场景参考图及必要的文字样式参考图。不要复制参考图原有的菜名，也不要让模型自行推测牛肉名称。仅调用一次生图以完成该张场景及文字，不预设后续标注调用。不同菜的标签不得互相重叠或遮挡大面积牛肉。

完成后实际检查文字是否准确、对应、清晰及有无漏标，并检查食物、产品和布局。如有错字、漏字或对应不明，保留成图并明确报告；不自动再发起一次编辑或重抽。用户明确要求修正时，再按已有图编辑流程处理。用户要求只要提示词时，提示词同样包含完整标签和对应位置，但不生图。

## 已有图片编辑

1. 实际查看每张目标图和可用的文字样式参考图，建立每个标签与画面位置的对应关系；结合原始产品图和生成记录核对牛肉名称，不把风格参考图中的文字或食材视为目标图的内容。
2. 参考用户给出的文字样式。没有指定参考时，可采用易读的浅黄色中文、黑色描边和轻微倾斜的生活化菜名样式，大小适应画面。文字放在相应菜品上或附近，避免相互重叠以及遮住大面积牛肉纹理；保持照片构图、食材和画面风格。
3. 使用当前环境的图像编辑工具，给每张图单独编辑。传入目标图与必要的样式参考图，并在提示词中准确逐字指定名称及位置；保留原图，不替换或新增食物。不要把先前生成的标注图误认为原始产品图。
4. 实际查看结果，检查中文文字、名称和对应位置、是否有漏标或错误标注、食物和画面的变化。如出现明显错误，视情况修正；如仍无法确保正确，应说明具体问题，不宣称全部准确。保存独立标注版，默认放当前工作区的输出目录，不覆盖原图；交付图片和可访问的文件链接。若图像编辑不可用，说明原因并提供可直接用于编辑的逐项标注清单或提示词，不声称图片已完成。
